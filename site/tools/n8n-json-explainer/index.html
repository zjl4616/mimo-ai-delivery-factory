n8n JSON 中文解释器

粘贴或导入 n8n 工作流 JSON，本工具会在浏览器本地生成：节点中文解释、简化流程概览与风险点清单。无需联网，无需后端。

输入

公开协作：一键脱敏（推荐）

如果你希望把 workflow JSON 发到公开渠道（Reddit / GitHub Issue）让别人帮你 review，请先脱敏。此功能在浏览器本地运行，不上传数据。

公开协作入口（GitHub Issue 模板）：打开 Issue 模板

免责声明（更保守）
  • 本工具为第三方独立工具，非 n8n 官方产品，不代表 n8n 立场或承诺。
  • 输出仅用于辅助理解，可能不准确/不完整/过时；最终以原始 JSON 与 n8n 官方文档为准。
  • 请勿粘贴包含明文密钥、token、客户隐私的数据；建议先做脱敏。
