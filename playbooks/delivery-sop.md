# Delivery SOP

## 1. Intake

Collect the discovery form and one real sample input/output pair.

## 2. Diagnose

Use the automation scorecard. Pick the smallest workflow that can prove value in 3 days.

## 3. Prototype

Build with the lowest moving-parts stack:

- spreadsheet or Markdown as data source
- local script, n8n, or Feishu workflow
- model-generated draft
- human review checkpoint

## 4. Test

Use at least 5 historical examples.

Track:

- accuracy
- time saved
- manual edits needed
- failure modes

## 5. Handoff

Prepare:

- how to run
- what to check daily
- how to update source data
- when to stop the automation

## 6. Upsell

Offer one of:

- monthly monitoring
- second workflow sprint
- content production workflow
- AI coding workflow setup
