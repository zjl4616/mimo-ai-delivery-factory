# P02 n8n JSON 中文解释器

把 n8n workflow JSON 转成可读的中文说明、流程概览与风险提示（纯前端，本地处理）。

## 目标用户

- 下载了 n8n 模板/工作流，但看不懂 JSON 的人
- 团队交付需要把工作流写成“能读懂的说明书”的人

## 使用方式

- 打开 `index.html`
- 粘贴 n8n workflow JSON 或选择本地 `.json` 文件
- 点击“生成中文解释”
- 在 “Markdown” 标签页复制/下载输出

## 边界与安全

- 这是第三方独立工具，非 n8n 官方产品
- 输出仅用于辅助理解；最终以原始 JSON 和 n8n 官方文档为准
- 不要粘贴明文密钥 / token / 客户隐私数据（建议先脱敏）
