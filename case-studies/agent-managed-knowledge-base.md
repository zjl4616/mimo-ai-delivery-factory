# Case Study: Agent-Managed Knowledge Base

## Scenario

An Obsidian vault is used as an operating layer for projects, content, customer follow-up, generated results, and WeChat/Feishu intake.

## Problem

Knowledge assets become valuable only when they drive daily action:

- project decisions
- content production
- customer follow-up
- reusable templates
- delivery checklists

## Solution Pattern

1. Keep raw intake separate
2. Extract project leads, customer leads, and content materials
3. Move mature material into publishable notes
4. Convert repeated work into templates and SOPs
5. Use AI agents to scan, summarize, and propose next actions

## Commercial Use

This can become a service:

- knowledge-base cleanup
- AI operating-system setup
- content pipeline setup
- customer follow-up dashboard
- weekly review automation

## Public Boundary

Publish structure and sanitized examples only. Keep raw messages, private links, and customer details private.
