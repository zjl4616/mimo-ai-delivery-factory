# Case Study: AI Coding Course Assets

## Scenario

Course materials already contain a strong curriculum arc:

```text
Environment -> Tool Use -> Workflow -> Office Automation -> Product Development -> Deployment -> Monetization
```

## Problem

Many learners can generate demos, but cannot turn demos into shipped, maintainable products.

## Reusable Productized Assets

- PRD template
- design document template
- technical plan template
- AI coding workflow
- code review checklist
- security scan checklist
- browser test checklist
- public demo case library

## Commercial Use

These assets can support:

- paid workshop
- founder setup sprint
- AI coding workflow consulting
- template pack
- community onboarding material

## Public Positioning

Move from "AI randomly generates code" to "AI participates in software engineering".
