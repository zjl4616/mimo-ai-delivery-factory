# Offer: AI Coding Workflow Setup

## Promise

Set up a founder or developer with a usable AI coding workflow: repo structure, agent instructions, spec templates, review checklist, and deployment-ready habits.

## Best Customers

- founders who want to build prototypes with AI
- developers already using Cursor, Claude Code, Codex, or OpenCode
- course students who can make demos but cannot ship reliably
- small teams trying to standardize AI coding

## Pain Points

- AI writes code but projects become messy
- prompts are scattered across chats
- no PRD/design/tech structure
- no repeatable review process
- demos do not become usable products

## Deliverables

- repository setup
- `AGENTS.md` or equivalent agent instructions
- PRD template
- design document template
- technical plan template
- code review checklist
- security and reliability checklist
- sample implementation flow

## Suggested Fixed Scope

### Basic Setup

- 1 repository
- 1 target project
- 1 onboarding session or written handoff
- price: RMB 999 to 2,999

### Founder Build Sprint

- setup plus one working prototype
- price: RMB 4,999 to 12,999

### Team Workflow Kit

- setup for multiple repos or team members
- price: RMB 19,999+

## Sales Hook

The jump is from "letting AI generate code" to "making AI participate in software engineering".
