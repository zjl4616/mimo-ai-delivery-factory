# P02 公开工作流 Review 交付服务（n8n）

## 定位

这是一个**轻量、公开、异步**的工作流审查/改造建议服务：用户在公开渠道提交**脱敏后的 n8n workflow JSON**（GitHub Issue 模板），MiMo 工厂用 P02 工具生成可读解释与风险清单，并在 Issue 中公开交付一份结构化 Review 报告。

核心原则：**公开协作、最小隐私、可复用交付、可追踪证据**。

## 适用人群

- 在网上下载/购买 n8n 模板，但 JSON 很难读懂、很难评估风险的人
- 团队交接：希望把“能跑的工作流”变成“可解释的文档”的人
- 想优化稳定性/可维护性（错误处理、重试、幂等、速率限制、超时）的 n8n 用户

不适用：

- 含明文密钥/token/PII（个人身份信息）且无法脱敏的工作流
- 需要登录你的系统/远程调试/访问私有数据的需求（本服务不做）

## 交付物清单（默认在 Issue 内交付）

- `review-report.md`：结构化审查报告（基于模板生成）
- 风险清单（启发式）：凭证/隐私、错误处理、超时/重试、循环/爆炸风险、外部依赖风险
- 改造建议：按优先级给出 3–10 条可执行建议
- 测试清单：最小测试用例与验证步骤（改造前后对比）
- 可选：脱敏后的“改造版 workflow JSON”（只有在用户明确授权的情况下提供）

## 流程（提交 → 审阅 → 交付 → 迭代）

1. 提交
   - 你先用 P02 工具在浏览器本地生成**脱敏 JSON**
   - 然后用 GitHub Issue 模板提交（公开留痕）
2. 审阅
   - MiMo 工厂读取 Issue 内容、解析 JSON、生成报告
3. 交付
   - 直接在 Issue 回复中交付（可复制 Markdown）
4. 迭代
   - 你可继续在 Issue 里追问，或提交新版 JSON 进行二次审阅（视为新一轮）

## 时间与范围

- 目标首次响应：72 小时内（以公开 Issue 时间为准）
- 范围：只围绕**工作流结构/节点配置/数据流/风险**给建议
- 不包含：性能压测、端到端联调、长期维护承诺、任何收入/增长保证

## 风险边界（必须读）

- 不保证收益：不对效率提升、成本节约、业务增长做任何承诺
- 不使用私域：不加微信/飞书，不私聊；全部在公开 Issue 中完成
- 不接触敏感数据：你必须在本地脱敏；发现敏感信息会提示你删改后重新提交
- 不代表 n8n 官方：本服务是第三方独立工具/建议

## 定价建议（先跑通验证，收款链接需用户确认）

> 现阶段建议以“免费交付 + 可选赞助”启动，先拿到真实样本与公开案例，再决定固定价。

- 免费档（社区贡献）
  - 交付：结构化报告 + 风险清单 + 改造建议（不提供改造后的 JSON）
- 付费档（深度支持，需用户确认收款链接后才启用）
  - 交付：更细的改造方案（含优先级/伪代码/注意事项）+ 可选脱敏后的改造版 JSON
  - 付费方式：公开、可验证的付款链接（例如 GitHub Sponsors / Gumroad / Ko-fi 等）

## 如何用 P02 工具生成脱敏 JSON 并提交 Issue

1. 打开工具页：`/tools/n8n-json-explainer/`
2. 粘贴/导入你的 n8n workflow JSON
3. 展开“公开协作：一键脱敏（推荐）”
4. 点击“生成脱敏 JSON”，再点击“复制脱敏 JSON”
5. 打开 Issue 模板（工具页内置链接），粘贴脱敏 JSON 并提交

## English (short)

Public, async workflow review: submit a **sanitized** n8n workflow JSON via a GitHub issue template, and we’ll reply with a structured review report (risks + refactor plan) in the same public thread. No DMs, no private data, no revenue promises.
