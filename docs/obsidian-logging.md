## Rule

The repository can hold implementation assets. Obsidian is the source of truth for the user's process memory, execution history, decisions, confirmation items, and narrative review.

Each run should write:

- timestamp
- selected route
- action taken
- files created or updated
- revenue signal
- next action
- `NEEDS_USER_CONFIRMATION`
