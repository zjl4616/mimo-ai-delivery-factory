# 48h Mission — P02 公共回复获客（n8n 社区/公开论坛）

时间窗：2026-05-27 ~ 2026-05-29（48h）  
目标：用“公开求助帖回复 + 工具辅助诊断”拿到 3 个真实样本（脱敏 JSON）进入 GitHub Issues  
边界：只做公开渠道；不私信、不动私域；不承诺结果；不刷屏。

核心转化链路：
1) 在公开求助帖提供**实质性排查点**（1-2 条可验证建议）  
2) 顺带给出工具（离线/脱敏/解释）  
3) 引导到 GitHub Issue（公开、留痕、可持续协作）  
4) Issue 内产出“风险清单 + 建议改造路径”→ 形成 case-studies

P1：
- Reddit：`r/n8n`、`r/automation`（如果有真实求助帖）
- GitHub：公开仓库 issues（出现 n8n workflow JSON、template debug 相关求助）

---

## 操作清单（每天 30–60 分钟）

### 1) 找 3–5 个目标帖（只选“真实问题”）
筛选条件：
- 近 30 天内
- 描述包含：JSON / expression / template / credentials / error
- 评论不多（更容易被看到）
- 不是明显“已解决/已关闭”

记录字段（追加到本文末尾表格）：
- URL
- 问题摘要
- 是否需要脱敏提醒
- 计划回复角度（1 句话）
- 回复状态（draft/sent/follow-up）

### 2) 回复策略（不硬广）
结构：
- 先确认问题 → 给 1–2 条排查建议
- 再给工具链接（“我用这个工具看 JSON 更快”）
- 最后给 Issue intake（“如愿意公开协作，可以贴脱敏 JSON”）

### 3) 跟进（48h 内至少 follow-up 1 次）
- 如果对方回复“已解决/仍有问题”：公开继续问关键字段（输入/输出预期、节点名、错误文本）
- 若对方愿意贴 JSON：提醒“务必脱敏”，并建议用工具的一键脱敏
