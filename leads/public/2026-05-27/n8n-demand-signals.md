# Public demand signals — n8n workflow JSON review / documentation

Date: 2026-05-27

## Observed pains (public-internet inferred)
- People share n8n templates/workflows, but exported workflow JSON is hard to review quickly.
- Sharing workflow JSON publicly risks leaking secrets/credentials → lowers willingness to ask for help.
- Teams want “readable docs” for workflows (handoffs, audit, onboarding).

## MiMo hypothesis
A browser-only tool that outputs readable docs **plus** a safe public sharing/sanitization flow will increase conversions into:
- public GitHub issue review requests (free)
- fixed-scope paid workflow review/refactor delivery (quote later when payment setup confirmed)
