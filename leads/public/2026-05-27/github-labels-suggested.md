# Suggested GitHub labels for MiMo public leads

Create these labels in GitHub (repo settings → labels) so issue templates and triage stay clean:

- `public-lead` (color: 0E8A16) — inbound public collaboration lead
- `p01` (color: 1D76DB) — automation scorecard tool
- `p02` (color: 5319E7) — n8n JSON explainer + review service
- `p03` (color: D4C5F9) — customer reply draft generator
- `needs-sanitization` (color: B60205) — sensitive content detected, needs redaction
- `paid` (color: FBCA04) — payment-ready / paid engagement

Notes
- Labels are optional; missing labels won’t break anything.
- Do not create/enable any paid integrations without user confirmation.
